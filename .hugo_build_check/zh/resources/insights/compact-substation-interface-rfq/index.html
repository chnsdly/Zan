箱式变电站询价前，应先核对哪些接口？

箱式变电站常被用于减少现场土建和设备集成工作，但它并不是一个“只看容量和外形尺寸”的单一产品。一个箱变通常会把外壳、变压器、中压开关、低压配电、电缆间隔、通风、保护、计量和土建接口放在同一个供货包里。如果这些接口在下单前没有说清楚，即使设备本体参数可用，也可能拖慢基础施工、电缆敷设、电力公司审查、安装或投运。

简短结论是：箱式变电站 RFQ 应明确一次系统图、供货边界、电缆进出线、基础接口、检修净距、外壳使用环境、接地方式、电力公司计量要求、保护与控制接口，以及需要提交的图纸和试验文件。最终配置仍需按项目图纸、供应商文件、当地规范、电力公司要求、AHJ 审查、出厂试验报告和投运方案确认。

本文用于帮助采购方和项目团队准备询价资料、识别澄清项，不能替代电气设计单位、EPC、注册电气工程师、电力公司或当地主管机构的设计结论。

把箱变当作接口包，而不是普通外壳

箱式变电站看起来是一台完整的金属外壳设备，但真正决定项目是否顺利的是每一个连接点。变压器、开关柜、外壳、基础、电缆沟、通风路径、排水、公众接触风险、吊装方式和门板开启方向都会互相影响。

因此，“一台 1250 kVA、11 kV/0.4 kV 箱变”这类描述通常只适合早期预算沟通，不足以支撑采购订单。RFQ 应说明每一侧连接什么、由谁负责哪个边界。

可随 RFQ 发送的箱变接口矩阵

下表不是通用设计标准，而是帮助海外工厂、EPC、园区和新能源项目在图纸冻结前，把不同报价放到同一技术基础上比较。

RFQ 接口为什么会影响订单采购方应提供或要求什么
一次系统图与运行方式进线电源、变压器容量、低压进线、母联、馈线、备用电源和未来扩展都会影响箱变布置。提供最新版一次系统图、正常/应急运行方式、电力公司边界、计量位置，以及是否预留未来馈线或第二台变压器位置。
中压侧中压间隔可能涉及负荷开关、断路器、环网柜、计量、保护继电器、避雷器、电缆终端或电力公司铅封点。写明中压电压、频率、短路研究依据、开关功能、保护要求、计量规则、电缆类型，以及中压设备是箱变内供货还是由其他范围提供。
变压器间隔油浸式和干式变压器对通风、消防、集油、噪声、检修和监测的要求不同。确认变压器类型、容量、电压比、阻抗目标（如项目指定）、分接方式、冷却、报警接点、温度监测、检修门和更换路径。
低压侧低压总开关、馈线、无功补偿、计量、ATS、通信和出线方向会改变占地与散热设计。提供馈线表、供工程复核的开关额定值、电缆规格、进出线方向、计量/CT 边界、未来馈线空间和 BMS/SCADA 信号表。
电缆进出线与基础底部进线、侧面进线、电缆沟深度、格兰板、电缆弯曲半径和基础开孔常常到现场才暴露问题。提供基础图、电缆沟路线、进出线方向、格兰板需求、土建限制、地坪标高、积水风险和吊装搬运路线。
外壳与环境IP 等级、防腐、日照、粉尘、湿度、凝露、防盗和公众接触风险会改变外壳细节。写明室内/户外、环境温度、海拔、沿海或腐蚀性环境、粉尘/潮湿程度、适用的 IP 或 NEMA 概念、加热器、通风、门锁和标识要求。
接地与等电位中性点处理、电缆屏蔽接地、外壳等电位、变压器箱体接地和接地故障表现都取决于项目。提供接地设计要求、中性点方式、电力公司规则、当地规范依据、接地排位置，以及谁负责接入现场接地网。
文件与验收缺少图纸和端子表会影响土建、电缆采购、电力公司审查和投运。要求提交外形图、基础图、一次图、接线图、端子表、附件表、铭牌资料、装箱单、试验报告和约定语言版本，并在发运前确认。

先看一次系统图，不要先锁定外壳尺寸

很多箱变问题来自一开始就讨论外形布置，而电气边界还没有说清楚。项目团队应先确认箱变是接收一路电力公司电源、两路环网电缆、发电机或光伏接口，还是备用进线；还要确认低压侧只是一个总出线开关，还是包含完整馈线柜、无功补偿和计量的低压配电段。

原因很简单：开关柜不是一个纯尺寸问题。断路器开断能力、联锁、保护继电器、母线结构、CT 位置、电缆终端和计量边界都会影响空间、散热、接线和投运试验。箱变外壳应服从这些工程决定。

电缆进出线和土建细节会改变布置

在海外项目中，电缆进出线是常见 RFQ 缺口。适合底部进线和预制电缆沟的图纸，不一定适合地下管道侧面进线；样本里看起来整洁的门板布置，到了现场可能会与墙体、围栏、邻近设备、电缆牵引路线或检修通道冲突。

制造冻结前，采购方应确认基础尺寸、电缆沟开口、吊点、卸货路线、门板开启方向、可拆面板、通风净距和主要部件更换通道。如果箱变安装在户外，还要结合现场团队复核洪水位、排水、防盗、公众接触风险和腐蚀暴露。这里可同时参考现场环境条件 RFQ 清单，因为箱变会把许多环境假设集中在一个成套设备里。

外壳要求必须结合真实现场

外壳标签本身不能证明设备适合现场。适用 IP 代码的项目，通常会把 IEC 60529 作为外壳防护等级参考。部分市场或项目也可能采用 NEMA、ANSI、GB/T、电力公司或当地外壳要求。RFQ 应写明采用哪套体系，以及它要解决的现场暴露问题。

即便如此，IP 等级或外壳类型也只是问题的一部分。通风口、过滤网、百叶、屋檐、抗凝露加热器、涂装体系、五金件、门封、门锁和检修净距，对真实运行同样重要。对于潮湿、粉尘、沿海、高海拔、公众可接触或强日照场景，外壳应按运行环境评审，而不是只当作一层金属壳。

变压器与开关柜边界要可追溯

变压器数据、中压开关数据、低压柜数据和附件清单，应从报价、图纸确认、工厂检验、发运、到货验收到投运保持一致。尤其当一个供方提供外壳和变压器，另一个团队负责保护定值、计量审查或下游配电柜时，边界更不能含糊。

采购方应要求供应商提交清晰的边界表，说明哪些装置包含在箱变内，哪些作为散件发运，哪些端子引至用户接线点，哪些功能属于项目保护与控制设计。变压器附件与报警接点清单可用于补充信号和附件部分。

发运前，数据表、图纸、端子表、装箱单和试验文件应描述同一供货范围。设备到场后，收货团队还要保留这些证据链；到货验收与临时存放检查清单覆盖了这一交接阶段。

标准是参考，不是审批路径

标准可以帮助采购方和供应商使用同一套技术语言，但不能替代项目规格书。变压器要求在 IEC 体系适用时，可能参考 IEC 60076-1 等文件。箱式变电站项目还可能涉及高压开关设备、预装式变电站、外壳、电力公司、IEEE、ANSI、GB/GB/T、消防、抗震或当地安装要求。

这些参考不能跨市场直接互换。服务于某个电力公司、国家、矿山、工业园、新能源站点或商业建筑的箱变，可能需要不同的文件和审批证据。RFQ 应写明适用市场、项目标准、电力公司规则和主管机构审查路径。最终验收应以批准图纸、最终数据表、试验报告、现场检查和投运程序为准。

可直接改写的 RFQ 条款

“请按所附一次系统图、现场布置、电缆沟图、电力公司要求和项目规格书报价箱式变电站。请分别说明变压器、中压开关柜、低压开关柜、外壳、计量、保护、辅助电源、接地和附件供货范围。”

“制造前请提交外形图、基础图、电缆进出线细节、通风布置、门板开启方向、检修净距、吊装方式、端子表、接线图、附件表和装箱单供审批。”

“请说明变压器、开关柜、外壳、接地、试验、文件和现场验收所采用的标准或当地规则。除非项目文件明确，不得默认 IEC、IEEE、ANSI、NEMA、GB/T、电力公司、DOE、EU 或当地要求可以互相替代。”

“最终设计仍需按批准的项目图纸、电力公司审查、当地规范、AHJ 要求、供应商数据表、出厂试验报告，以及合格人员执行的投运试验确认。”

一个实用决策规则

当项目团队能够回答三个问题时，箱式变电站才适合进入正式采购：设备每一侧连接什么，外壳需要承受什么现场条件，以及哪些文件能够证明最终供货范围。如果其中任何一个答案缺失，就应先暂停报价比较，要求澄清，而不是把不同假设下的报价当作同等方案。

更清楚的 RFQ 不是为了让文件变长，而是为了避免把本该在设计阶段解决的问题，藏进一台看似完整的箱式变电站里。
